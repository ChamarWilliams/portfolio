# Chamar Williams: portfolio

Built on [Magic Portfolio](https://github.com/once-ui-system/magic-portfolio) (Once UI + Next.js), exported as a static site and deployed to GitHub Pages at https://chamarwilliams.dev.

- Site text and links: `src/app/resources/content.js`
- Colors and effects: `src/app/resources/config.js`
- Project pages: `src/app/work/projects/*.mdx`
- Interactive demos: `public/demos/` (plain HTML, CSS, and JS, embedded into project pages)

```
npm install
npm run dev      # local preview
npm run build    # static export to ./out
```
