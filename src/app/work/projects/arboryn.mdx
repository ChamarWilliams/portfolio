Arboryn is a local-first three-way merge engine for Roblox object trees, written in Luau with Rojo. The goal is to merge two people's changes to the same place safely.

The repository is in Phase 0, which asks one question before the product proceeds: can a Studio plugin observe and round-trip enough of a real DataModel to support trustworthy semantic merging? The current code is a Luau capture and measurement harness with a reflection-derived property inventory, explicit capture gaps instead of silent omission, and a native .rbxm round-trip probe. No merge engine exists yet, and real Studio capture results have not been collected, so Phase 0 has not passed. The design document is public in the repository.

Source: [github.com/ChamarWilliams/arboryn](https://github.com/ChamarWilliams/arboryn).
